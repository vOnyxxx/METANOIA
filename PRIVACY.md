# Privacy

METANOIA processes files locally through FFmpeg and FFprobe. The application has no accounts, telemetry, analytics, or automatic uploads. It does not transfer information to networked systems unless the user explicitly requests an operation that does so.

Local job history records input/output paths, status and errors under the current Windows user's local application data directory. Generated previews are stored in the user's temporary directory. Files and logs may contain personal information; review them before sharing a diagnostic report.

Downloading dependencies, obtaining releases through GitHub, and using SignPath for code signing are separate development/distribution services governed by their respective privacy policies. Signing does not upload the end user's multimedia files.
